NDVI → Impervious Area Detection

NDVI = (NIR − Red) / (NIR + Red)

Pixels with NDVI < 0.2 computed from Landsat 8/9 Band 4 (Red) and Band 5 (NIR) are masked as “Built-up / Impervious Area” and converted into GeoJSON polygons. This is done by the backend/process_real_nasa.py script from local GeoTIFF files or from real Landsat scenes via the Planetary Computer STAC API.

SCS Curve Number Model

S = 25400 / CN − 254 (mm)
Q = (P − 0.2·S)² / (P + 0.8·S) ; Q = 0 if P ≤ 0.2·S

S: maximum potential retention, P: rainfall depth (mm), Q: surface runoff depth (mm).

Runoff volume: V = (Q / 1000) × Area (m²) → m³.
